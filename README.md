# Quill · 리포트를 읽어주는 금융 과외

증권사 리포트를 근거로, 사회초년생과 바쁜 직장인에게 **채권·ETF 중심 자산 배분**을
눈높이에 맞춰 설명하는 서비스의 **화면 프로토타입**입니다.

> ⚠ **지금은 디자인·플로우 검증용입니다.** DB, 수집 파이프라인, 추천 알고리즘, 로그인은
> 아직 붙지 않았습니다. 화면에 나오는 증권사 리포트·발췌문·수익률·시황은 **전부 지어낸
> 샘플**이며 실제 자료가 아닙니다. 투자 권유나 자문이 아닙니다.

## 빠른 시작

```powershell
cd C:\Users\kimch\Desktop\finance-ai-webapp
powershell -ExecutionPolicy Bypass -File .\start.ps1   # 실행 (http://localhost:5174)
powershell -ExecutionPolicy Bypass -File .\stop.ps1    # 종료
```

포트는 **5174**입니다. 옆 폴더 `healthcare-ai-webapp`(5173)과 동시에 띄울 수 있습니다.

| 주소 | 화면 |
|---|---|
| `/` | 대문 — 챗봇 입력 · 오늘의 시황 · 포트폴리오 미리보기 · 수집 파이프라인 · 취급 상품 |
| `/survey` | 투자 성향 설문 (8문항) |
| `/analysis` | 분석 진행 — 단계별 처리와 참고 리포트가 쌓이는 화면 |
| `/result` | 최종 결과 — 성향 · 배분 · 상품별 해설 · 실행 순서 |
| `/library` | 리포트 서재 — 근거 자료 목록 |
| `/library/:id` | 리포트 상세 — 3줄 요약 · 인용 원문 · 태깅 신뢰도 |

챗봇은 모든 고객 화면 우측 하단에 떠 있습니다.

### 관리자 콘솔 `/admin`

고객 사이트와 **완전히 분리된 셸**입니다. 사이트 헤더도 챗봇도 들어오지 않습니다.
기획서의 수집 파이프라인이 그대로 운영 화면이 됩니다.

| 주소 | 화면 |
|---|---|
| `/admin` | 개요 — 오늘 파이프라인 퍼널, 검수 대기, 근거 부착률, 설문 이탈 지점 |
| `/admin/ingest` | 수집 현황 — 일자별 실적, 소스별 크롤링 잡 상태 |
| `/admin/review` | **검수 큐** — 신뢰도 미달 건의 태그를 고쳐 승인하거나 반려 |
| `/admin/reports` | 리포트 — 공개/보류 전환, 어느 상품이 인용 중인지 |
| `/admin/rules` | 필터 규칙 — 포함·제외 키워드, 신뢰도 하한, 최소 쪽수 |
| `/admin/products` | 상품 · 배분표 — 성향별 자산 비중 편집 (합 100% 강제) |
| `/admin/survey` | 설문 · 가중치 — 문항별 채점 비중 조정 |
| `/admin/quality` | 챗봇 응답 — 근거 없이 답한 건 추적, 답 못 한 질문 목록 |

**관리자 설정이 고객 화면에 실제로 반영됩니다.** `lib/overrides.ts`가 얇은 오버레이
층이라, 리포트를 보류하면 서재와 근거 칩에서 즉시 빠지고, 배분표·가중치를 고치면
다음 진단부터 결과가 달라집니다. 관리자가 손대지 않은 항목은 코드 기본값을 그대로
씁니다.

> 인증이 없습니다. 주소를 아는 사람은 누구나 들어올 수 있으므로 상단에 그 사실을
> 계속 띄워 뒀습니다. 외부에 올리기 전에 반드시 로그인을 먼저 붙이세요.
> 모든 변경은 브라우저 localStorage에만 저장되고 서버로 나가지 않습니다.

관리자 화면은 고객 사이트와 같은 팔레트를 쓰되 **밀도를 올리고 만년필 필체를
워드마크에만 남겼습니다.** 오래 들여다보며 판단하는 운영 도구라 읽는 속도가
분위기보다 우선합니다.

## 디자인

### 색

미색 종이(`#FFFCF6`) 위에 **골드 브라운**(`#8A6A32`)을 얹었습니다. 순백을 쓰지 않아
화면 전체가 종이처럼 보이고, 그림자도 회색이 아니라 갈색 계열로 떨어집니다.

브라스(`#B08D57`)는 **선·밑줄·서명에만** 씁니다. 면으로 칠하지 않습니다.
고급스러움은 금색 면적이 아니라 여백·정렬·선 굵기에서 나온다는 전제입니다.

자산 배분 차트는 색상환을 돌리지 않고 **브라스 명도 사다리 하나**(`--a1`~`--a6`)로만
그립니다. 명도만으로 순서가 읽히므로 색각 이상에서도 구성이 무너지지 않고,
화면 톤도 흐트러지지 않습니다. 다른 색상(청 `#2C6E8F`)은 벤치마크 한 계열에만 허용합니다.

### 글자 — 3단 구성

| 단계 | 서체 | 쓰는 곳 |
|---|---|---|
| `--font-script` | **Italianno**(영문) + **나눔손글씨 펜**(한글) | 브랜드 워드마크, 히어로·섹션 제목, 진단 결과 유형명 |
| `--font-display` | 고운바탕 | 중간 크기 제목, 인용 |
| `--font` | Pretendard | 본문 · UI · 숫자 전부 |

만년필 필체는 영문과 한글 모두 **가는 펜촉 계열**로 맞췄습니다. 다만 획이 얇아
**28px 아래로는 쓰지 않습니다.** 본문을 필체로 쓰면 읽는 속도가 떨어지므로,
읽어야 하는 글은 전부 Pretendard가 맡습니다. 가독성이 먼저입니다.

손글씨(`.hand`)는 **한 화면에 두세 번을 넘기지 않습니다.** 과외쌤이 여백에 적어 준
메모처럼 쓸 때만 효과가 납니다.

폰트는 전부 **self-host**(`@fontsource`, `pretendard`)라 외부 CDN 없이 오프라인에서도
같은 화면이 나옵니다.

### 버튼 · 입력

요청대로 **경계선을 쓰지 않습니다.** 테두리 대신 색면·여백·아주 옅은 그림자로만
눌리는 곳임을 알립니다. 모서리는 전반적으로 크게(pill) 가져가 경계감을 더 줄였습니다.
누를 때는 그림자를 안으로 넣는 대신 살짝 가라앉기만 합니다.

## 설문과 진단 알고리즘

문항은 **금융투자협회 표준투자권유준칙**이 요구하는 항목(연령 · 투자기간 · 지식과 경험 ·
재산 상황 · 소득 원천 · 손실 감내 · 투자 목적)을 골격으로 삼고, 사회초년생이 실제로
걸려 넘어지는 지점인 **비상금** 문항을 하나 더했습니다.

채점은 일부러 단순합니다. 선택지 점수(0~4) × 문항 가중치를 합산해 0~100으로 정규화한 뒤
5단계(안정형 · 안정추구형 · 위험중립형 · 적극투자형 · 공격투자형)로 나눕니다.

| 문항 | 축 | 가중치 |
|---|---|---|
| q6 손실 시나리오 | 손실 감내 | **30** |
| q2 자금 사용 시점 | 기간 여력 | 20 |
| q3 금융 지식·경험 | 지식·경험 | 15 |
| q4 투자 비중 · q5 소득 안정성 · q8 비상금 | 감당 여력 | 각 10 |
| q7 수익 기대 | 수익 기대 | 10 |
| q1 연령 | 기간 여력 | 5 |

### 규칙이 점수를 덮어씁니다

`finalAlloc()`에서 성향 점수보다 **안전 규칙을 먼저** 적용합니다.

- **1년 안에 쓸 돈** → 점수가 아무리 높아도 장기 국채·주식형 ETF를 전부 뺍니다.
- **비상금 없음** → 현금성을 25%까지 먼저 채우고 나머지를 비례 축소합니다.

결과 화면에서 이 개입이 있었다는 사실과 이유를 사용자에게 그대로 보여 줍니다.

| 관리자 저장 | localStorage 오버레이 | 서버 설정 API + 변경 이력(누가 언제 무엇을) |
| 설문 문항 | 코드 고정 (가중치만 편집) | DB로 이관. 이미 진단받은 사용자 결과 처리 방침부터 정할 것 |
| 프런트 | 순수 CSS + 토큰 | 21st.dev 컴포넌트를 붙이려면 Tailwind 도입 필요 |

**DB 선택** — 수집 설계안에는 MySQL, 역할 분담에는 Supabase(PostgreSQL)로 적혀
있어 서로 다릅니다. 리포트 본문 임베딩을 쓸 계획이라면 `pgvector`가 있는 **Supabase**
쪽이 유리합니다. 정하고 나서 스키마를 확정하는 편이 좋겠습니다.

### 성능 메모

한글 웹폰트 3종을 self-host 해서 첫 로드에 폰트가 약 3.5MB 내려옵니다.
로컬에서는 체감되지 않지만, 외부 배포 전에는 서브셋을 줄이거나 고운바탕 700을 빼는
정리가 필요합니다.

## 브랜드 이름

`Quill`(만년필 촉)은 팔레트·서체 방향과 맞춰 임시로 붙인 이름입니다.
바꾸실 거면 `components/Layout.tsx`의 워드마크와 `index.html`의 `<title>`,
그리고 `lib/store.tsx`의 저장 키(`quill.answers.v1`)만 고치면 됩니다.
