# DESIGN 브랜치 — GUI 디자인 변경 내역

> **이 브랜치는 `frontend/` 디자인 영역만 수정합니다.**
> `backend/`, `collector/`, `supabase/`, 설정 파일은 단 한 파일도 건드리지 않았으므로
> main의 백엔드 작업과 병합할 때 백엔드 충돌은 발생하지 않습니다.
> 베이스는 main(`8b11b55`)이며, main이 이미 반영한 개선(사이드바 CTA 게이팅,
> 마이페이지 가드, api.ts 세션 관리 등)은 그대로 두고 그 위에 디자인만 얹었습니다.

## 디자인 원칙

색 면(블럭)과 상자를 걷어내고, **가는 헤어라인(경계선)과 타이포그래피(잉크 농담·골드 포인트)**만으로
위계를 만듭니다. 근거 각주 패널의 조판이 기준입니다. 원형은 관례가 원형인 곳
(선택 마커, 캐러셀 화살표)에만 의도적 예외로 씁니다.

## 바꾼 것

| 영역 | 내용 |
|---|---|
| 첫 진입 온보딩 | 필수 6문항 스테퍼 오버레이(`OnboardingStepper`) — 진행 바, 선택형 자동 진행, 마지막 단계에서 위험점수·기준 비중 미리보기 후 저장. 진단 기록이 있으면 뜨지 않음 |
| 스테퍼 선택지 | 면 블럭 → 각주 조판: 골드 명조 번호 + 헤어라인 구분, 선택은 잉크 연함→진함(+골드 체크) |
| 리포트 서재 | 카드 그리드 → **부채꼴 카드 덱**(`ReportFan`, GSAP): 7슬롯 팬, 좌우 순환, 호버 시 옆 카드 밀림, "n / 전체" 카운터 |
| 대화 오프닝 | 깃펜 아이콘 → 골드 눈썹 라벨로 현재 모드 표기(리서치/훈수). 모드별 예시 질문 분리(훈수는 '살까 말까' 고민형 4문) |
| 예시 질문·필터 | 알약 면 → 글자 + 세로 골드 헤어라인 (서재 필터·대화 예시 공통 문법) |
| 컴포저 | 모드 전환을 입력창 왼쪽 + 버튼(위로 열리는 메뉴)으로, 전송 버튼은 면·경계 없는 라인 아이콘, 아이콘 20px |
| 스트리밍 본문 | 글자별 잉크 번짐·만년필 촉 애니메이션 제거 → 평문 + 깜빡이는 세로 막대 커서(`.caret`) 하나 |
| 트레이스·토글 | 색 면 칩/알약 → 색 글자 + 헤어라인 행 구분, 패널은 골드 헤어라인으로 시작하는 각주형 |
| 사이드바 버튼 | 면 버튼 → 헤어라인 위 글자(조건 다시 잡기 = 골드 헤어라인 + 골드 글자) |
| 포트폴리오 | 좌우 2단 → 위→아래 한 흐름: ①위험점수·슬라이더·배분·근거 한 패널(안쪽 헤어라인 구분) ②자산군 가로 3열(세로 헤어라인, 900px↓ 1열 전환) ③파라미터 한 줄 스트립. 자산군 순서를 배분 막대 ORDER와 일치 |
| 드래그 질문 마커 | 면·경계 없는 골드 말풍선 아이콘(플로팅 챗 버튼과 동일한 `IconChat`) |
| 에이전트 표식 | 원 배경 제거 — 골드 깃펜 라인만 |
| 진단 CTA 문구 | 전 화면 2종으로 통일: 진단 전 "성향 진단 시작" / 재실행 "조건 다시 잡기" |

## 없앤 것 (육안 기준 — 데이터·로직은 유지)

- 서재 상단 주황 경고 배너, 검색창 행(덱 카운터와 중복)
- 팬 카드 하단 분류 태그(마크업은 유지, `display:none`)
- 스테퍼 문항 하단 Capacity/Tolerance 축 알약
- 접힌 사이드바에서 "조건 다시 잡기" 글자가 레일 밖으로 삐져나오던 표시 버그
- 트레이스 라벨의 ✅ 이모지, 모드 메뉴의 🔬/💬 이모지(라인 아이콘으로 교체)

## 병합 안내

- 이 브랜치의 변경은 전부 `frontend/` 안입니다. 백엔드와의 충돌 = 0.
- main과 겹치는 프론트 파일 중 기능 배선(api.ts, AppSidebar, Layout, MyPage)은
  main 버전을 그대로 따랐으므로 diff가 없습니다. 디자인이 갈리는 파일
  (SelectionAsk, Library, Portfolio, 스타일시트)만 검토하면 됩니다.
- `npm run build`(tsc + vite) 통과 확인 완료. `gsap` 의존성이 추가되었습니다.
